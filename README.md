## <img src="https://media.giphy.com/media/LnQjpWaON8nhr21vNW/giphy.gif" width="28"> Featured Projects

<details>
<summary><b>📡 P1 — Real-Time Network Fault Detection (Embedded + ML)</b></summary>

<br/>

A mini communication network built from real hardware that **generates its own labeled fault dataset** — no synthetic data. Arduino Nano and ESP32 exchange framed packets over UART/MQTT while injected faults are captured, windowed, and classified.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | C (firmware), Python, Scikit-learn, MQTT/Mosquitto, ESP32, Arduino Nano |
| **Scale** | Streaming telemetry at 100 ms intervals, 30 s rolling feature windows |
| **Performance** | F1-macro & AUC-ROC optimized via GridSearchCV over LR / SVM / RandomForest |
| **Security** | CRC8/MAXIM frame integrity, sequence-validated 5-byte protocol |
| **Impact** | Reference architecture for edge fault classification in NOC environments |
| **Repository** | [`Portfolio-DataScience-IA`](https://github.com/sforzin/Portfolio-DataScience-IA) |

Four fault classes (`normal`, `uart_degraded`, `wifi_degraded`, `link_down`) are derived from per-window metrics — jitter, CRC errors, frame loss, RSSI, WiFi latency. The full pipeline runs from bare-metal signal generation to a StandardScaler → model-selection ML stack, demonstrating an unbroken chain from hardware to inference.

</details>

<details>
<summary><b>📈 P2 — Network Traffic Forecasting & Capacity Planning</b></summary>

<br/>

Multivariate time-series forecasting of link utilization to anticipate congestion and inform capacity provisioning before SLA breaches occur.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, Pandas, Statsmodels, PyTorch (LSTM/Temporal), Plotly |
| **Scale** | Multi-link telemetry, hourly and sub-hourly seasonality modeling |
| **Performance** | MAPE-optimized against classical baselines (ARIMA, Prophet) |
| **Security** | Reproducible, versioned datasets with drift monitoring |
| **Impact** | Proactive congestion alerts for NOC dashboards |
| **Repository** | [`Portfolio-DataScience-IA`](https://github.com/sforzin/Portfolio-DataScience-IA) |

Rolling-window and Fourier-based seasonal features leverage DSP intuition to separate trend, seasonality, and noise before modeling.

</details>

<details>
<summary><b>🕸️ P6 — Graph Neural Network for Fault Propagation</b></summary>

<br/>

Models the physical network as a graph and learns how faults propagate across topology, predicting cascade risk from node- and edge-level features.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, PyTorch Geometric, NetworkX, GNN (GraphSAGE / GAT) |
| **Scale** | Topology graphs with hundreds of nodes and weighted links |
| **Performance** | Node-classification AUC on held-out failure events |
| **Security** | Isolated, auditable inference pipeline |
| **Impact** | Root-cause localization support for NOC operators |
| **Repository** | [`Portfolio-DataScience-IA`](https://github.com/sforzin/Portfolio-DataScience-IA) |

A differentiator beyond generic ML tracks — bringing message-passing architectures to real network-integration problems.

</details>

<details>
<summary><b>🤖 P8 — RAG Agent over Telecom Documentation</b></summary>

<br/>

A retrieval-augmented agent that answers integration and troubleshooting questions grounded in vendor manuals, RFCs, and internal runbooks, with tool-use for live diagnostics.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, FastAPI, vector DB, LLM orchestration, RAG + agents |
| **Scale** | Multi-document corpus with chunked, embedded retrieval |
| **Performance** | Groundedness and retrieval-precision evaluation |
| **Security** | Source-cited answers, scoped tool permissions |
| **Impact** | Cuts NOC lookup time and standardizes integration knowledge |
| **Repository** | [`Portfolio-DataScience-IA`](https://github.com/sforzin/Portfolio-DataScience-IA) |

Closes the portfolio arc: from embedded signal capture (P1) to autonomous, knowledge-grounded assistance (P8).

</details>
